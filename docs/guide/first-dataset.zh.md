# 做出第一份数据集

[English](first-dataset.md) · **简体中文**

这一页带你从一个空文件夹走到导出一个角色的数据集。假设程序已经装好（[安装](install.zh.md)）。每一步都附有讲全部细节的页面链接（英文）。

## 需要准备什么

每一集需要：

- **视频**（`.mkv`、`.mp4` 等）；
- **主字幕**，台词要和对白对得上（`.ass` 或 `.srt`）。每一句字幕切成一个片段，也就是你要标注的一小段声音。最好是说话的语言，比如日语动画就用日语字幕，因为导出的文字来自主字幕；
- 可选的**辅助字幕**，也就是你看得懂的字幕，比如翻译。标注时显示在每句台词下面，不影响别的。

## 1. 启动程序

双击 Windows 下载包里的 `start.bat`，或者运行：

```powershell
uv run avoc app workspace
```

`workspace` 是你自己选的文件夹，里面放各集、标注和导出的数据。程序会在浏览器里打开 `http://127.0.0.1:8765`（[选项](../reference/commands.md#app)）。

## 2. 加第一集

工作区里还没有集数时，打开的就是「加一集」表单。

1. 在最上面选「**收集声音做什么用**」。选「朗读文字（GPT-SoVITS 等）」两条路都留着；选「只要声音（RVC 等）」，主字幕也可以用翻译，但这样切出来的集数以后再也拿不到文字。每个工作区只选一次。
2. 用「浏览…」选视频、主字幕和可选的辅助字幕，或者直接粘贴路径。
3. 偏移留空就自动测量（需要 [Hugging Face 令牌](install.zh.md#hugging-face-令牌用于自动对时间)），也可以自己填。
4. 按「**开始**」。

程序会把人声和音乐分开，按每句字幕切出一个片段，再计算声纹。声纹描述一个人的声音，用来比较片段像不像。在 RTX 4060 笔记本显卡上，一集大约要 12 分钟。运行期间可以关掉对话框继续干别的。想一次加一整季，选「多集，一集接一集」（[加集数](../features/adding-episodes.md)）。

## 3. 在「分组」里标第一批

按 **G**。机器会把听起来像的台词放进同一组。

1. 勾上同一个人的台词；整组都是一个人时，按「全选」。
2. 在底部栏选是谁：目标角色（数字键）、「**不是目标**」（Q），或「**新目标**」（N），新建一个目标角色，名字以后再起。

目标角色就是你要收集台词的角色。其他人一律标「不是目标」，拿不准的也一样（[标注基础](../features/labeling.md)）。

## 4. 在「场景」里过一遍

按 **S**。这一集的台词按顺序列出，同时播放画面。

- **Enter** 接受机器猜的第一个；数字键选目标角色；**Q** 标「不是目标」。
- **Shift** + 数字表示是这个目标角色，但质量低，用于背景音太重或两个人同时出声的台词。质量低的台词不会导出。
- **X** 把听不出是谁的台词先放一边；**L** 多放前后文。

一个目标角色确认满 10 句、别人也标了几句「不是目标」以后，机器就开始猜。每标一句，它都会马上重新学一次（[场景](../features/scenes.md)）。

## 5. 在「角色」里逐个核对

按 **O**，打开你的角色。最前面是机器归给它的台词，从最不自信的开始。

1. 按 **P**（「连播待核对」）连着听。
2. 听到错的，就标成正确的人，或者按 Q。
3. 剩下的都没问题时，按 **Shift+Enter** 一起确认。

然后看「可能漏掉的」：机器没归给这个角色、但有可能是它的台词（[角色](../features/characters.md)）。

## 6. 导出

按 **E**。勾选角色，选格式（每个角色一个文件夹、只要声音，或者带每句文字的 GPT-SoVITS 格式）和输出文件夹，开始导出。「打开文件夹」可以看到结果（[导出](../features/export.md)）。

## 出了问题

- **Z** 撤销上一步；「撤销」旁边的时钟按钮可以撤回更早的任意一步（[撤销和历史](../features/labeling.md#undo-and-history)）。
- 加集数中途停了（比如显存不够），在「没做完的集」下面按「接着做」，或者在命令行里再加一次；会从停下的地方继续。
- `uv run avoc doctor` 检查电脑（[安装](install.zh.md#检查电脑)）。
- 在程序里按 **?** 查看所有按键，或者看[快捷键](../reference/shortcuts.md)。
