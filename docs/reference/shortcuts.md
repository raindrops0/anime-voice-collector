# Keyboard shortcuts

Press `?` in the app to see the same list. What each label means is in [Labeling basics](../features/labeling.md).

## Moving and playing

| Key | What it does |
| --- | --- |
| J / ↓, K / ↑ | Next line, previous line |
| Space | Replay this line from the start; clicking the selected line again does the same |
| L | More context: step through none, 5 seconds on each side, and 15. It stays when you move to another line |
| R | Hear a reference line of the machine's top guess |
| G / S / O / E | Go to Groups / Scenes / Characters / Export |

## Labeling

| Key | What it does |
| --- | --- |
| Enter | Accept the machine's top guess |
| 1 – 9 | Label as the matching target character in the bottom bar |
| Shift + 1 – 9 | The same target character, but low quality: not used to recognize anyone, left out on export |
| Q | Not a target |
| X | Ignore line: set it aside under "Ignored"; not trained on, not exported |
| N | Label as a new target character, to be named later; with video, crop an avatar next |
| Backspace | Clear this line's label and go back to the machine's guess |
| Z | Undo the last step; keep pressing to go further back. For an earlier step alone, use the history next to Undo ([undo and history](../features/labeling.md#undo-and-history)) |

## In one view

| Key | Where | What it does |
| --- | --- | --- |
| F | Scenes | Show only "To do"; press again to go back to your ticks |
| P | Characters | Play the lines one after another, least sure first |
| Shift + Enter | Characters | Confirm the ticked "To do" lines the machine gave this character |
| Enter / Esc | Cropping an avatar | Save / cancel |
| Shift + click | Groups | Tick every line between the last ticked one and this one |
