## Set up

**The Windows download** is a zip on the [Releases page](https://github.com/raindrops0/anime-voice-collector/releases/latest), about 16 MB. It holds this repo, `uv.exe`, and two files to double-click:

- `start.bat` starts the app on the folder `workspace` inside the download. The first start downloads Python and the libraries, about 5 GB; later starts take a few seconds. To open another workspace, drag its folder onto `start.bat`, or run `start.bat D:\my-workspace`; options after the folder go to `avoc app`, such as `--port 8800`. Keep its window open while you use the app.
- `terminal.bat` opens a command prompt where every command on this page works as written, such as `uv run avoc doctor` or `uv run hf auth login`.

Python, the libraries and the downloaded models stay inside the unzipped folder ([how](../scripts/release/env.bat)), so deleting the folder removes everything; only the Hugging Face token stays in your user folder. Unzip it to a short path such as `D:\avoc`: Windows refuses file paths longer than 260 characters, and the libraries already use about 170 of them. To update, unzip the new version over the old folder: your workspace, the libraries and the models stay, and the next start installs only what changed.

With `git clone` instead, run the two commands below in the repo folder.

You need FFmpeg on your `PATH`. On Windows, the app's first page has an "Install it for me in one click" button: it runs [install_ffmpeg.ps1](../src/avoc/install_ffmpeg.ps1), which installs [Scoop](https://scoop.sh) if you have none and then FFmpeg with it, all without administrator rights, and avoc can use it at once without a restart. To install it yourself, run `scoop install ffmpeg` if you have Scoop, or download the Windows build from [ffmpeg.org](https://ffmpeg.org/download.html), unzip it, and add its `bin` folder to the `PATH` environment variable. `avoc doctor` says the same when FFmpeg is missing. For the GPU setup and notes on each model, see [TOOLS.md](TOOLS.md).

```powershell
uv sync --locked
uv run avoc doctor
```

`doctor` lists each item in turn: the operating system, the graphics card, FFmpeg, the voice separation model, the Hugging Face token, and the free disk space. Items marked "missing" must be fixed first. Items marked "optional" can be left alone and the tool still works. "Untested" means a system other than Windows: avoc mostly works there, but it is tested on Windows only.

## Processing a new episode

```powershell
uv run avoc add workspace "Episode 08.mkv" --subs "Episode 08.ja.srt" --display-subs "Episode 08.zh.ass" --offset -0.95
```

**Give subtitles in the spoken language as `--subs` when you have them**, and a translation you read as `--display-subs`. Each clip's text is then its own subtitle line, and an entry where two people speak is cut into one clip per person ([how](HOW_IT_WORKS.md#flow)). The secondary subtitles are only shown while labeling; if they do not line up, `add` warns and still finishes, and `set-display-subtitles` below attaches them later. Cutting from a translation also works, but then the episode has no text and can only be exported as sound ([why](DECISIONS.md#cutting-clips)); to get text later, delete the episode and add it again.

The interface can also add an episode, with the same steps ([how](#labeling-and-correction-interface)). `add` does everything in one command: it extracts the audio track, separates the voices, cuts clips along the subtitle lines, and then computes the three voiceprints that the interface needs. If the episode name is left out, it uses the next unused `epNN` in the workspace. You can also name it with `--name`, or in the "Episode name" box of the add form; a name such as `usagi-s1-ep01` keeps several anime or seasons apart in one workspace. When the main subtitles are not in the spoken language, `add` still finishes but warns that the episode can only be exported as sound. If the run stops halfway (for example, because there is not enough GPU memory), fix the problem and run the same command again. It picks up where it stopped: clips that are already cut and voiceprints that are already computed are not recomputed. If the clip-cutting step itself fails, the half-built folder is deleted.

Both the video and the subtitles are required. The subtitles can be in any common text encoding, and the dialogue [styles](HOW_IT_WORKS.md#glossary) are picked automatically ([how](HOW_IT_WORKS.md#flow)). `add` prints the styles it used and the ones it left out. To check a file first, run `uv run avoc styles "subtitles"`: it lists each style with its line count, time range and sample lines, and marks the ones that would be picked with `*`. If the choice is wrong, give the styles yourself, for example `--styles "Default,Default - Top"`. In the app's add form, the same list appears under the subtitle path once it is filled in, with check boxes. If a warning says some lines still contain marks, see [SUBTITLES.md](SUBTITLES.md#when-it-warns). The audio track is extracted from the video by default. If you have a lossless audio track on the same timeline, give it with `--audio`. If its length differs from the video by more than 0.5 seconds, it is refused. `--spoken ja` (or `zh`, `en`, `ko`) says which language the voices speak. The voices are taken from the audio track tagged with it, and exported text must be in it. When it is left out, a Japanese track is used if the video has one, else the default track; the language comes from the track's tag, and with no tag Japanese is assumed. `add` prints which track it used and lists the others ([how](HOW_IT_WORKS.md#flow)). `--device` defaults to `auto`: it uses the NVIDIA GPU if there is one, and otherwise the CPU. On the CPU, voice separation switches to full precision. The `--device` option of `prepare` and `embed` works the same way.

**Giving `--offset` saves the speech detection, when you know it.** For the same source and the same subtitle group, the offset is often stable (measured on episodes 1 to 3 of one anime: -0.95, -0.96, -0.96). When it is given, speech detection does not run at all, and the whole episode takes that one value. But subtitles made for another release of the video can differ from episode to episode and even jump within one (one season measured -0.11 to -1.30 seconds, with jumps of up to 0.9 seconds around minute 12), so leave it out when unsure. If it is not given, the offset is measured with pyannote, and an episode whose timing jumps gets an offset for each part; `add` prints them, such as "-1.09 seconds; from 12:12, -0.65 seconds" ([how](HOW_IT_WORKS.md#flow)). That requires you to accept the terms on the [model page](https://huggingface.co/pyannote/speaker-diarization-community-1) first, create a Read token on the [tokens page](https://huggingface.co/settings/tokens), and then run `uv run hf auth login` and paste it. An account is free. The add form shows these steps when the token is missing. Without a token, `add` and `prepare` report the error right at the start. They do not stop halfway through.

If you prefer to run the steps one at a time, `add` is equal to the following:

```powershell
uv run avoc prepare "video" --subs "subtitles" --name ep08 --out workspace/episodes/ep08 --offset -0.95
uv run avoc embed workspace/episodes/ep08 --model anime-va
uv run avoc embed workspace/episodes/ep08 --model anime-char
uv run avoc embed workspace/episodes/ep08 --model redimnet2-b6
uv run avoc quality workspace
```

`avoc quality` computes the features of the [low-quality hint](HOW_IT_WORKS.md#glossary) for every episode of the workspace that lacks them, such as episodes added before the hint existed. It loads WavLM-large, which takes several GB of memory; on an RTX 4060 Laptop GPU the episodes of one season took 6 to 13 seconds each. `--device` works as for `add`.

## Labeling and correction interface

### Starting the app

The workspace is a folder. Its `episodes/` subfolder holds the episodes (the output of `add` or `prepare`), and labels are saved automatically in `labels/`. This repo uses the folder `workspace/`, which git ignores.

```powershell
uv run avoc app workspace
```

Open `http://127.0.0.1:8765` in your browser. If port 8765 is in use, the next free port is taken and printed. If the same workspace is already open, nothing new is started: the command prints that server's address, process ID, start command and start time, opens its page and ends. `--port` sets the port; then only that port is tried. `--no-open` stops the browser from opening by itself. `--reload` is for development: it restarts the server when a Python file of avoc changes ([CONTRIBUTING.md](CONTRIBUTING.md#web-app)). `--model` can be repeated, to use only the named voiceprint models. The part of the address after `#` records the current view, episode, character and selected line, so after a refresh you return to the same spot. Episodes whose voiceprints are not all computed (usually because `add` was interrupted) are not loaded. They are listed on the command line at startup, and the other episodes work as usual. The first time a workspace with episodes but no labels is opened, a getting-started guide opens: the four views in the order they are used, each with what it shows and how to work in it, from the first label to the export. Open it again with "Guide" in the top bar, or from the shortcuts dialog (`?`). When the workspace has no episodes at all, the page is the "Add an episode" form, with one line on what the tool does.

### Adding an episode

Adding an episode from the interface: on that first page, or with "+ Add an episode…" at the top of the episode menu. Give the video, the language the characters speak (by default taken from the audio track; the form shows which track and language; change it only to collect a dub), the main subtitles (best in that language), and, if you like, secondary subtitles you read, such as a translation (`--display-subs` on the command line). The form shows the language of each subtitle file. When the voices are for reading text aloud (GPT-SoVITS and such), the main subtitles must be in the spoken language (a bilingual file counts): with a translation there, Start stays off and the form says to put the translation under secondary subtitles, or, before the first episode, to choose "Sound only". With "Sound only" picked, a translation is accepted as the main subtitles, and the form warns in large type that such an episode can never give text later; if unsure, pick reading text aloud. Press "Browse…" next to each box to pick the file in the system's file window, or paste the path ([where the window opens](UI_DESIGN.md#typing)). If the window cannot open (for example a Linux Python built without Tk, or no desktop), the page says so; paste the paths instead. The offset box is filled in with the last episode's offset. Start runs the same `avoc add` as on the command line, in a separate process. The progress lines show as it goes, and library warnings show only if it fails. Separating the voices of one episode took about 12 minutes on an RTX 4060 Laptop GPU; the voiceprints take under a minute. You can close the dialog and keep labeling; a button at the top shows that it is still running, and the new episode appears in the menu when it is done. Stop ends it. If it stops or fails before the clips are cut, the half-built folder is deleted, and carrying on cuts them again from the start; that step is the slowest. After the clips are cut, finished steps are kept. Either way the episode is listed under "Unfinished episodes" with a "Carry on" button, which reruns it with the files it was started with. Those files are noted in `adding.json` in the workspace until the episode is added, so the list is the same after the server restarts, including a restart under `--reload` while an episode was being added; that run stops by itself when its server ends. An episode whose clips were never cut also has a "Give up" button, which deletes its note and any half-built folder. Only one episode is added at a time.

### Adding a whole season

To add a whole season, pick "Several, one after another" under "How many episodes". Give the folder of the videos, the folder of the main subtitles (it may be the same folder) and, if you like, the folder of the secondary subtitles. The files are paired by the episode number in their names (`S02E03`, `[03]`, ` - 03 `, `第03話` and such; the year, `1080p`, `x265` and `10bit` are not taken for it). Each episode is named from the box after "Names" plus its number, such as `usagi-s2-ep03`; the box starts with the part before the number of the latest episode's name. Episodes already in the workspace, or with no video or no subtitles, are listed but cannot be ticked. When an episode has two videos, such as two encodes, a box appears to keep only the files whose name holds some text, such as `x265`. The audio track and subtitle styles are shown for the first ticked episode. Left as they are, each episode picks its own styles; once changed, every episode uses the ticked ones. The offset box starts empty, so each episode is measured on its own: two episodes of one season from the same source and subtitle group measured -1.30 and -0.67. Every episode is checked before any starts, and all problems are listed at once. All of them are noted in `adding.json` before the first starts. Then they are added in order. A failed episode does not hold up the rest. The progress box lists each one as waiting, adding, added, failed or stopped. Stop ends the one running and the rest of the queue. The ones not added are listed under "Unfinished episodes", also after a restart. With two or more there, "Carry on with all, one after another" queues them again. While a queue runs, Start puts more episodes at its end.

### Target characters and labels

Give names only to the people you want to collect (the target characters). Label everyone else "Not a target" with the Q key, including anyone you are not sure is a target. Clips where several people speak and none of them is a target are also labeled "Not a target", and so are clips that are not speech, such as cheers and sound effects. The target character's own laughs and sighs count as the target's voice, so label them as the target. Each target character has two options, chosen in one go. The number key gives the clean target. Shift plus the same number gives "target, low quality". Use the low-quality option for clips with heavy background sound or with several people talking at once. Those clips are not used to recognize the character. They are skipped on export and written to `rejected.tsv`. With two target characters, the bottom bar has 5 options in all: four for the two targets (clean and low quality for each), plus "Not a target". Next to each target character's guess on the left there is also a "Low quality" button. When you change a clip to the clean target or to "Not a target", "Low quality" is removed automatically. There can be several target characters. You can add or remove them at any time in the Characters view. For how existing labels are handled when you add or remove a target, see [HOW_IT_WORKS.md](HOW_IT_WORKS.md#target-characters-and-not-a-target).

### The views

The line between the picture side and the list can be dragged to change their widths. The width is remembered in the browser, and double-clicking the line puts it back.

The tabs at the top come in two boxes. The first box holds the episode menu with Groups and Scenes, which show only that episode. The second box holds Characters, which covers every episode, so switching the episode does not change it. Export, on the right of the bar, also covers every episode.

- **Groups (G)**: start here when there are no labels yet. The machine puts clips that sound alike into one group, so you can label many lines at once. Tick the lines of one person, or press "Select all"; Shift+click ticks every line between the last ticked one and this one. Then pick who they are in the bottom bar, or with its keys: the target characters (number keys), "Not a target" (Q), and "New target" (N), which makes them a new target character whose name can be filled in later. While any lines are ticked, these label the ticked lines; with none ticked, they label only the line playing. The group's heading names the character the machine guesses most often in it. When a group mixes several people, tick and label them in turns. A labeled line stays in the group, shows what it was labeled as, and can no longer be ticked. Undoing with Z restores the group as it was.
- **Scenes (S)**: lists all the lines by episode and scene, in order. The left side shows the picture and the machine's ranking of its guesses. "Vocals only" is on by default: the picture plays, but the sound switches to the separated vocals. To hear the original sound, click "Original sound". Beside it you can choose 1x, 1.25x, 1.5x or 2x speed, and the reference audio plays at the same speed. Clicking a speed, even the one already picked, plays the line again from the start at that speed. Both settings are remembered, so they stay after a refresh. Pressing Space, or clicking the selected line again, replays it. When you cannot tell who is speaking, choose "More context" below the line: "None", "±5 s" or "±15 s" plays that much extra time on each side. L steps through the three. The choice stays when you move to another line and after a refresh. If a line cannot play, the picture says why, and "Cut again" throws away the saved clip and cuts it again. Clicking the picture pauses or plays; the icon in its bottom right corner shows which. Each target character has a reference sound. Enter accepts the first guess. The number keys pick a target character from the bottom bar. Q labels "Not a target". Lines shorter than 1 second, and lines of only one or two syllables such as あっ, are marked "Too short, ignored" ([the rule](HOW_IT_WORKS.md#glossary)). They do not count as work to do. Each line of the episode is in exactly one part, and the tick boxes at the top choose which parts are listed, each with its number of lines: first the two kinds of "Confirmed", "Clean" and "Low quality"; then the two kinds of "To do", "Not guessed yet" and "Not confident" (the only ones ticked at first), and at the end of the same row, past a divider line, "Confident", which the "To do" box does not tick; "Optional" (labeling them helps the machine learn) with "Maybe low quality" (every unlabeled line with the "maybe low quality" hint, including those the machine set aside; labeling one moves it out), as in Characters; and the two kinds of "Ignored": "Too short" (a short line stays there after it is labeled) and "Ignored by you". The box in front of a kind ticks or clears all its parts, and shows a dash when only some are ticked. The ticks are remembered in the browser. A line you label stays in the list until the ticks or the episode change, even when its label moves it to a part not ticked. F, or the "Only to do" button, lists only "To do"; pressing it again goes back to the parts ticked before. A line the machine finds maybe low quality shows a red dashed "Maybe low quality" tag with its chance; it is only a hint, learned from your "low quality" labels. When you cannot tell who a line is, for example a passer-by voiced by a target's voice actor, press X ("Ignore line"): it moves to "Ignored", is not used for training and is not exported; Backspace or Z takes it back. You can still label them if you want: a labeled short line is exported and used for training like any other, and one marked low quality is still left out.
- **Characters (O)**: at the top of the left side are the target characters. Below them are characters that are no longer targets but still have labels. The last row is "Not a target". Each row shows, on the right, how many lines have been confirmed, how many the machine assigned to it, and the total length of the confirmed dialogue. Open a character to see first the lines the machine assigned to it, starting with the least confident. "Play all to check" (P), in the bar above them, plays them one after another. When you hear a wrong one, label it as the right person, or press Q for "Not a target", and it leaves this list. After listening to the rest, press Shift+Enter ("Confirm the other N lines") to confirm the remaining lines. Below that is "Maybe missed": lines the machine did not assign to this character, but that might be it. They start with the most likely, and are labeled like any other line ([which lines](HOW_IT_WORKS.md#target-characters-and-not-a-target)). Tick boxes under the name choose which parts are listed, each with its number of lines, in the same order as in Scenes: first the two kinds of "Confirmed", "Clean" and "Low quality" ("Not a target" has one "Confirmed" box); then the two kinds of "To do", "Not confident" and "Confident" (the lines counted in orange on the left); then, after "Optional" (labeling them helps the machine learn: its next guesses get better), "Maybe missed" and "Maybe low quality" (every line the machine gave this character that nobody labeled and that has the "maybe low quality" hint, including those the machine set aside; never confirmed at once; the least likely to be low quality first, as those are the clean lines the hint most likely got wrong); and the two kinds of "Ignored", as in Scenes: "Too short" (lines the machine gave this character that the rule skips and nobody labeled; one labeled as this character is under "Confirmed") and "Ignored by you" (ignored lines the machine would give this character). Only "To do" is ticked at first, and the ticks are remembered in the browser. "Confirm the other N lines" (Shift+Enter) confirms only the "To do" lines that are ticked. Each box looks like the pill on its lines; on a line given by the machine the pill shows only the machine's chance, orange when it is not confident. The buttons beside the avatar, under the name, rename or merge the character and set or unset it as a target; clicking the avatar crops a new one from the picture. "Not a target" can also be opened. Each line there shows which target character the machine thinks is closest, and with what probability. Confirmed lines are sorted starting from those closest to a target, so wrong labels show up first.
- **When the machine guesses again**: each label retrains the machine, and its guesses change on other lines too. Those lines show their new guess at once, but Scenes and Characters do not add, take out or reorder lines by themselves, so nothing moves under your hand. The message at the bottom says what would change, for example "3 lines to take out", and "Update list", in that message or next to Undo in the bottom bar, applies it; switching the episode, view or character also does. "Confirm the rest" confirms only the lines shown whose newest guess is still that character. Tick "Auto" next to "Update list" to have the list update by itself each time; the choice is remembered in the browser.
- **Export (E)**: choose the characters (the target characters start ticked) and the format (one folder per character with sound only, or GPT-SoVITS with each line's text). You can export only the lines that a person has confirmed, or also include the lines the machine is confident about. When it is done, "Open the folder" shows the export in the file manager. For GPT-SoVITS, the text is in each episode's spoken language ([how](HOW_IT_WORKS.md#text-in-the-spoken-language)). The list under "Text of each line" shows, for each episode, the language spoken (change it there if the audio track's tag was wrong; "assumed" means there was no tag), where the text comes from, and how many target lines have no matching text. An episode cut from a translation has no text and can only be exported as sound. Clips without text are not exported; the details are in `rejected.tsv` in the export folder. While labeling, such clips already show "No text to export" with the reason. The output folder starts as `exports/<today's date>` inside the workspace, shown in full, or `<date>-2` and so on once that one holds an export; change it, or pick another with "Browse…". A relative path typed there starts from where `avoc app` was started, as in every path box. What the voices are for is chosen once, at the top of the add form before the first episode ("What the voices are for"; it starts at reading text aloud, which keeps both ways open), and kept in the workspace (`labels/purpose.json`); after that the add form and Export only show it. Switching midway is not supported yet ([roadmap](ROADMAP.md#labeling-interface)). With "Sound only (RVC and such)", the labeling views leave out everything about exported text ("No text to export" and its reasons), the add form accepts a translation as the main subtitles, and Export has only the sound-only format. With reading text aloud, Export can still write sound only, for RVC, without changing the choice. A workspace made with `avoc add` alone has no choice recorded and works as reading text aloud until the add form records one.

### Names and avatars

Identifying people mainly relies on avatars, and names can be left blank:

- Press N to label the current line as a new target character. A dialog asks for its name; you can leave it blank, and it then gets a temporary name such as "Character 1" or "Character 2". "Cancel" (Esc) takes the new character back, and the lines return to how they were. Later, in the Characters view, click "Name" to fill in the real name. In the New target dialog, a name another character already has is refused. In "Name" or "Rename or merge" in the Characters view, typing another character's name merges the two; the dialog says so before you save, and Z undoes it. "Not a target" is never a name.
- A character with no avatar shows a picture generated from its number. The background color, shape and pattern all change together, so different characters are easy to tell apart at a glance.
- Cropping an avatar: when a new character is created and there is a picture of the line, the same dialog also crops an avatar ("No avatar" keeps only the name). Later, click the avatar to crop it. You can do this from the confirmed lines on the left, or from the avatar at the top of the Characters view. Drag the box to move it. Drag the bottom-right corner or use the scroll wheel to zoom. Use the slider to change the frame, and press Enter to save.

### Undo, shortcuts and page settings

Each label is saved to disk and the model is retrained right away. Backspace (or Delete) clears the label of the current line and returns it to the machine's guess. Confirmed lines also have a "Clear label" button on the left. Z undoes the last step, and you can keep pressing it to go further back. Creating, renaming and merging characters are also undone. Avatars and setting or unsetting a target character are not part of undo. The clock button next to Undo opens the history, newest step first. Point at a step to take back just that step ("Take back"), or to take back every step after it ("Back to here"); tick several steps to take them back together. Taking back is a step of its own, so the history only grows, and a take-back can itself be taken back. A line that a later step changed again keeps the later change. Undoing a rename takes every line of that character back to the old name, including lines labeled after the rename. A step is left out, with a message, when a name it needs back is now used by another character. Imported labels, and every step before them, cannot be taken back. Press `?` to see all the shortcuts. The page uses a light color scheme by default. You can switch to dark mode at the top right. Next to it, the EN / 中文 button switches the page between English and Chinese; the first time, the page follows the browser's language. Messages from the server, such as errors, follow the page language. Both choices are remembered in the browser.

### Filling in older episodes

Commands for filling in information for older episodes:

```powershell
uv run avoc set-video workspace/episodes/ep01 "Episode 01.mkv"
uv run avoc set-subtitles workspace/episodes/ep01 "Episode 01.zh.ass"
uv run avoc set-display-subtitles workspace/episodes/ep08 "Episode 08.zh.ass"
uv run avoc set-spoken-language workspace/episodes/ep01 ja
```

- `set-video`: records the video for an episode that was processed before `prepare` required it. If the length does not match the audio track, it is refused.
- `set-subtitles`: adds subtitles to an episode that has none recorded. The offset is worked out from the existing clips, and the dialogue text is found by matching the times that overlap.
- `set-display-subtitles`: attaches subtitles in a language you read to an episode cut from subtitles you don't. They are only shown while labeling. The offset is measured automatically; if it does not line up with the main subtitles, it is refused.
- `set-spoken-language`: corrects the language an episode speaks when the audio track's tag was wrong or missing. The voices already cut stay as they are; to cut from another audio track, add the episode again with `--spoken`.
